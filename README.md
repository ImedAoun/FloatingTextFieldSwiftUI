# FloatingTextFieldSwiftUI

🚀 Un champ de texte SwiftUI avec un label flottant, personnalisable, simple et moderne — parfait pour vos formulaires iOS.

![FloatingTextFieldSwiftUI Demo](demo.gif) <!-- Remplace ou supprime si pas encore de GIF -->

---

## ✨ Fonctionnalités

- ✅ SwiftUI pur (sans UIKit)
- 💬 Animation fluide du placeholder vers le label
- 🔐 Support des champs sécurisés (`SecureField`)
- 🎨 Personnalisation des couleurs, textes, styles
- 📱 Compatible iOS 15+

---

## 📦 Intégration

Pour utiliser `FloatingTextField` dans votre propre projet SwiftUI :

1. Copiez les fichiers suivants depuis ce repo vers votre projet :
   - `Views/FloatingTextField.swift`
   - (Optionnel) `Extensions/View+Extension.swift` si utilisé
2. Importez le fichier dans vos vues :
   ```swift
   import SwiftUI
